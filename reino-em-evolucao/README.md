# Reino em Evolução

Protótipo pessoal de hábitos e evolução em formato RPG de fantasia medieval.

## Abrir

<https://ygorfortunato.github.io/publicados/reino-em-evolucao/>

## Dados da jornada

O app funciona no navegador e guarda o progresso localmente. Na aba **Reino**, é possível:

- baixar um backup em JSON;
- importar esse backup em outro dispositivo;
- reiniciar a jornada, mediante confirmação.

## Estrutura

```text
reino-em-evolucao/
├── index.html
└── assets/
    ├── classes-fogueira-feminino.png
    ├── classes-fogueira-masculino.png
    ├── fantasy-bonfire.jpg
    └── towers-campfire.png
```

O GitHub Actions deste repositório publica automaticamente toda pasta na raiz que contenha um `index.html`.
