## Como publicar um projeto novo

Crie uma pasta na raiz com um `index.html` e envie para a `main`. O workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) publica cada pasta em `https://ygorfortunato.github.io/publicados/<pasta>/`.
